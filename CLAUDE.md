## Design System
Read docs/DESIGN.md before visual or UI work: it defines the fonts, colors, spacing, and
aesthetic direction. Ask the user before departing from it. When reviewing or QA-ing
UI, flag code that doesn't match docs/DESIGN.md.

## Handoff
Start every new session by reading docs/HANDOFF.md: project status, owner's standing rules, how to run,
AI cost decisions and the prioritized open items. Update it when status or decisions change.
