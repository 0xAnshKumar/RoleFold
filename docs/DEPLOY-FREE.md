# Deploy RoleFold with no card: Vercel (web) + Render (API + worker) + Neon (Postgres)

Written 2026-11-21. Northflank was dropped: its free plan asks for a card before creating anything.

```
Browser ── Vercel (Next.js) ──/v1──> Render web service "rolefold-api" (uvicorn + worker, one container)
                                                  │
                                                  └── Neon Postgres "rolefold" (aws-us-east-1), database `hunt`
```

## What is already done (2026-11-21)

- Neon project `rolefold` (org "Ansh", region aws-us-east-1, Postgres 18). `bootstrap.sql` ran: roles `hunt_owner`,
  `hunt_app`, `hunt_worker` (no RLS bypass) and `hunt_admin` (bypass), database `hunt`. Migrations ran to `0010`.
  Neon note: on Postgres 16+, the owner must be granted `hunt_owner WITH SET TRUE` before `CREATE DATABASE ... OWNER`.
- The image (`api/Dockerfile`) was smoke-tested against Neon with `sh scripts/start-all.sh`: `/readyz` 200,
  ~170 MB idle (Render free = 512 MB).
- `render.yaml` (repo root) defines the service; the salt and the AI-key encryption key are generated by Render.

## Steps left

1. Render: sign up with GitHub (no card), **New → Blueprint**, pick the RoleFold repo. Render asks for the
   `sync: false` values: `GEMINI_API_KEY`, `DATABASE_URL`, `WORKER_DATABASE_URL`, `MIGRATION_DATABASE_URL` (the three
   Neon URLs were generated locally and are kept outside the repo), `OIDC_AUDIENCE` (Google client id).
2. Google sign-in: OAuth client (Web), redirect `https://rolefold-green.vercel.app/auth/callback`.
3. Vercel env: `API_URL=https://<render-service>.onrender.com`, `OIDC_ISSUER=https://accounts.google.com`,
   `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET`, `APP_URL`, `SESSION_SECRET`; redeploy.
4. Check `https://<render-service>.onrender.com/readyz` returns 200, then sign in on the Vercel URL.

## Free-plan limits to know

- Render free sleeps after 15 min without traffic; the first request then takes about a minute. Background tasks
  pause while it sleeps (the app keeps polling, which keeps it awake during a task).
- Render free disk is wiped on every restart/deploy: uploaded files and exported PDFs/Word files are short-lived
  (re-export to download again); deletion tombstones are lost too. The database is not affected.
- Neon free: 1 GB per project; compute sleeps after 5 min idle and wakes on the next query.
- New migrations: run `alembic upgrade head` with `MIGRATION_DATABASE_URL` (from a laptop, or a Render shell).
